PART 1 · 5분

계정 준비

캔바와 AI 도구에 로그인하고, 탭 2개를 열어 둬요. 다 됐으면 하나씩 눌러 체크하세요.

  • ✓
    노트북 준비충전기도 함께요. 휴대폰·태블릿으로는 실습이 어려워요.
  • ✓
    구글 계정 확인아이디와 비밀번호를 확인해요. 캔바와 AI를 이 계정 하나로 써요.
  • ✓
    캔바 로그인 — canva.com 열기 ↗오른쪽 위 가입 → Google로 계속하기 → 내 구글 계정 선택. 이미 있으면 로그인만.
    유료(Pro) 안내가 나오면 닫기나 나중에를 눌러요. ‘7일 무료 체험’이 뜨면 시작해도 괜찮아요. 7일 뒤 자동으로 무료로 바뀌어요.
  • ✓
    제미나이 로그인 — gemini.google.com 열기 ↗새 탭에서 열고 로그인 → 같은 구글 계정으로 들어가요. ChatGPT를 쓰고 계신 분은 그대로 써도 괜찮아요.
  • ✓
    탭 2개가 열려 있어요캔바 탭 + 제미나이 탭. 이 실습 페이지까지 3개면 완벽해요.
막히면 손을 들어 주세요. 강사가 자리로 찾아가요.
PART 2 · 8분

문구 만들기

AI에게 카드뉴스 표지에 넣을 제목과 부제를 받아요. 먼저 무엇을 알릴지 정해요.

🏪 가게 · 매장○○카페, ○○공방, ○○식당
→ 가게 이름 + 대표 메뉴·상품
🏢 회사 · 단체캐다(keda), ○○영농조합, ○○협동조합
→ 회사 이름 + 주력 사업·서비스
🙋 개인 · 전문가강사 홍길동, ○○ 작가, ○○ 공인중개사
→ 내 이름 + 전문 분야
가게가 없어도 괜찮아요. 내 이름도 훌륭한 브랜드예요.

1크기 먼저 정하기

3프롬프트 ② 이미지 만들기

제미나이에 붙여넣을 말문구를 받았던 그 대화창에 이어서 붙여넣어요.
아직 [ ] 빈칸이 남아 있어요. 위 칸을 채우거나 여기서 직접 고쳐 주세요.
  1. 같은 대화창에 이어서 붙여넣고 Enter
  2. 30초~1분 기다려요
  3. 마음에 안 들면 “다시 만들어줘”를 한 번만 입력해요
한글이 조금 깨져도 괜찮아요. PART 4에서 캔바로 바로잡을 거예요.

PART 4 · 12분

매직 레이어로 수정하기

AI가 만든 이미지는 글자와 그림이 한 장에 붙어 있어서 고칠 수가 없어요. 매직 레이어가 글자 · 그림 · 배경을 따로따로 떼어 줘요. 이제 하나씩 고칠 수 있어요.

  1. 캔바 홈에서 Magic Layers(매직 레이어)를 찾아 눌러요
  2. 미디어 선택에서 업로드를 눌러, 저장한 이미지(또는 샘플)를 골라요
  3. 편집기 열기를 누르고 잠시 기다려요
  4. 보라색 선이 이미지 위에 뜨면 이제 수정할 수 있어요!
끝나면 글자와 그림을 하나씩 눌러 보세요. 따로따로 선택되면 성공이에요.

✓분리 후에 할 수 있는 것

✏️ 글자 고치기글자를 두 번 빠르게 눌러(더블클릭) 새로 입력해요. 깨진 한글이나 오타를 바로잡아요.
🎨 색 바꾸기바꿀 부분을 누르고, 위쪽의 색상 팔레트를 눌러 원하는 색을 골라요.
↔️ 옮기고 지우기누른 채로 끌면 옮겨져요. 필요 없는 것은 Delete 키로 지워요.
잘못 눌렀다면 Ctrl + Z (맥은 ⌘ + Z). 바로 전으로 되돌아가요.

PART 5 · 5분

저장하고 올리기

완성한 카드를 오늘 만든 블로그의 첫 게시물로 올려요.

1캔바에서 완성한 카드 내려받기

  1. 캔바 화면 오른쪽 위 공유 버튼을 눌러요
  2. 다운로드를 눌러요
  3. 파일 형식이 PNG인지 확인해요
  4. 보라색 다운로드 버튼을 눌러요 → [다운로드] 폴더에 저장돼요

2프롬프트 ③ 블로그 글 받기

이미지와 함께 보낼 말브랜드 이름·분위기는 PART 2에서 적은 대로 들어가요.
아직 [ ] 빈칸이 남아 있어요. 위 칸을 채우거나 여기서 직접 고쳐 주세요.
  1. 제미나이 입력창의 + 버튼을 눌러 완성한 카드 이미지를 올려요
  2. 복사한 프롬프트를 붙여넣고 Enter
  3. 마음에 드는 제목과 본문을 복사해요
AI가 쓴 글은 꼭 한 번 읽어 보고, 내 말투로 고쳐서 올려요.

3네이버 블로그에 첫 글 올리기

  1. 내 블로그에서 글쓰기를 눌러요 — 글쓰기 바로 열기 ↗
  2. 제목에 브랜드 이름을 넣어요
  3. 사진을 눌러 저장한 카드를 올려요
  4. 소개 글을 붙여넣고 내 말투로 다듬어요
  5. 오른쪽 위 발행을 눌러요
